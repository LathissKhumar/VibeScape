## Features

- **Music Personality Archetypes** — 12 distinct archetypes generated by AI analysis of your listening data
- **Sonic DNA Analysis** — Audio feature extraction (energy, valence, danceability, acousticness) from real track metadata
- **Music Twin Matching** — Cosine similarity on 64-dimensional genre-weighted embeddings to find compatible listeners
- **Genre Evolution Timeline** — Real-time genre and emotional trajectory visualization from listening history
- **3D Music Universe** — Interactive Three.js galaxy visualization of your top artists
- **Personalized Recommendations** — Genre adjacency graph + vibe-matched artist suggestions
- **Feature Flags System** — Database-backed toggleable features with live admin panel
- **Activity Tracking** — Client-side event analytics with localStorage persistence
- **Export & Share** — Download your personality card as PNG or OG image (1200×630)
- **Dark Futuristic UI** — Glassmorphism, neon gradients, fluid typography, cinematic animations

## Architecture

### Data Pipeline

```
User Login → YouTube Music Search → Last.fm Track Match → Tag-Based Audio Features
     ↓              ↓                      ↓                      ↓
  Credentials    Genre-based          Track search          35+ tag→feature mapping
  Provider       artist search        + artist info         ML computation
     ↓              ↓                      ↓                      ↓
  Session Token  20 Artists           10 Tracks             7 Audio Features
     ↓              ↓                      ↓                      ↓
  ───────────────────────────────────────────────────────────────────
                              ↓
                    Gemini 2.0 Flash AI
                    Personality Analysis
                              ↓
                    Dashboard Rendering
                    (PersonalityHero, Galaxy,
                     AudioRadar, Timeline, etc.)
```

### Embedding System

Music Twin matching uses a **hybrid embedding approach**:

1. **Genre Taxonomy Vectors** (dimensions 0-6): 35 genres mapped to 7 audio feature dimensions (energy, valence, danceability, acousticness, instrumentalness, speechiness, tempo)
2. **Artist Profile Vectors** (dimensions 7-63): Deterministic hash-based profiling for artist identity
3. **Cosine Similarity**: Compares 64-dimensional vectors between users to find compatible listeners

### Audio Feature Computation

Instead of random values, audio features are computed using a **tag-based ML model** from Last.fm:

1. **Track Search** — Finds matching track on Last.fm
2. **Tag Extraction** — Fetches top 10 tags for the track (e.g., "rock", "energetic", "male vocalists")
3. **Tag→Feature Mapping** — 35+ genre/mood tags mapped to audio feature vectors
4. **Averaging** — Multiple tags are averaged to produce final feature values

Example tag mappings:
```
"electronic" → { energy: 0.8, valence: 0.6, danceability: 0.8, acousticness: 0.05, tempo: 128 }
"sad"        → { energy: 0.3, valence: 0.15, danceability: 0.2, acousticness: 0.6, tempo: 80 }
"party"      → { energy: 0.85, valence: 0.9, danceability: 0.9, acousticness: 0.1, tempo: 125 }
```

Fallback: If no tags match, computes features from track duration and listener count.

## API Reference

### `POST /api/recommend/personalized`

Returns personalized music recommendations based on user profile.

```json
{
  "profile": {
    "genres": ["indie rock", "electronic"],
    "topArtists": ["Radiohead", "Daft Punk"]
  }
}
```

### `POST /api/recommend/vibe-compatibility`

Computes vibe compatibility between two user profiles.

```json
{
  "profileA": { "genres": [...], "topArtists": [...] },
  "profileB": { "genres": [...], "topArtists": [...] }
}
```

### `POST /api/profile`

Persist user profile or find similar users.

```json
{ "action": "persist", "profile": { "genres": [...], "topArtists": [...] } }
{ "action": "find_similar", "userId": "anonymous", "limit": 3 }
```

### `GET /api/feature-flags`

Returns all feature flags.

### `POST /api/feature-flags`

Toggle a feature flag.

```json
{ "key": "galaxy_3d", "value": true }
```

### `POST /api/analytics`

Track user events.

```json
{ "type": "section_view", "section": "sonic-dna", "timestamp": 1234567890 }
```
